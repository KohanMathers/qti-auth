Add the vanilla HTML/CSS/JS web foundation. The `web` service serves an app shell, a
branding-driven `theme.css`, a `styles.css` baseline with focus, reduced-motion and
touch-target rules, an ES module client-side router that reads `/meta/features` and
handles cross-site surface pairs, an `en-GB` locale catalogue and a Problem Details
code → message catalogue that covers every kit error.
